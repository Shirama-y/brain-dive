# BRAIN DIVE — 診断書 / MIND EXCAVATION v2

開始画面はメインビジュアルの1画面のみです。「はじめる」から直接診療室へ進みます。音楽のON/OFFと設定は同じ画面で変更できます。

Vite + TypeScript + Canvas 2D製の短編心理探索パズルです。STAGE 01「月曜の朝」を、タイトル → 診療室 → 問診 → 瞳への潜行 → 掘削探索 → 記憶の整理 → 帰還 → 医師の評価・確認を経た架空の診断書 → SESSION COMPLETE → タイトルまで遊べます。

v2は落ちものパズルから全面移行しました。ペア落下・回転・4個消し・重力連鎖・NEXT・落下モードの切替・旧勝利判定は削除しています。カウンセラーが未知の情報を発見し、言葉の出どころを理解する体験を中心にしています。

## 起動

Node.js 22.12以上（24推奨）とnpm。Macで次を実行してください。

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

```sh
npm test          # 描画に依存しない盤面・進行・入力テスト
npm run build     # TypeScript型チェック + 本番ビルド
npm run preview   # dist/ をローカル表示
npm run dev:mobile # 同じWi-Fiのスマホから開く場合
```

スマホでローカル版を試す場合、`dev:mobile`が表示するNetwork URLを使います。スマホの`localhost`はMacを指しません。HTMLをFinderから直接開くのではなくHTTPサーバーを使ってください。

## 遊び方

- 固定の10列×12行マップです。初めから全体の内容は見えません。
- 光の細い縁があるブロックをクリック・タップして掘ります。開いた通路と上下左右で隣接する場所だけ掘れます。斜めや遠方には掘れません。
- 不安（紫・心配顔）、自責（ピンク・眉）、疲労（青・重い目）は通常の感情ブロック。掘ると通路になり、隣の輪郭が見えます。重力や同色消去はありません。
- 防衛・隠れた通路・残響は条件付きです。選択すると必要な手がかりを表示します。壁は掘れません。
- 「観察」は選択地点付近の未発見マスを最大3つ発見します。隠れた通路の光の切れ目や、近くの記憶の気配も分かります。遠方のマスでは観察できません。
- 白金色の記憶を掘ると、探索が止まり、文字送り付きの記憶カードを表示します。「記憶」から後で読み返せます。
- 掘削と観察は集中力を1消費します。初期値・最大値は6。集中力はカウンセラーが一度の探索で扱う情報量を表すゲーム上の制約です。
- 集中力0でも失敗にはなりません。「問診」で質問を1つ選ぶと6まで回復します。どの質問にも正誤はなく、追加の情報が異なります。既に掘った通路、発見した記憶、手がかり、解いた謎は保持されます。
- 記憶の閲覧・分類・関連づけは無料です。3枚を「出来事」「他者の言葉」「本人の解釈」に分類すると奥の防衛が解放されます。深層では、上司が言った言葉と本人の解釈を別々の記憶として結びつけます。
- 関連性が分かると上司の残響は奥へ退き、深層ゲートを掘れるようになります。戦闘や上司の撃破はありません。

## 操作

| 操作 | PC | スマートフォン |
| --- | --- | --- |
| 掘削 | マップを左クリック / 選択後Enter | マップをタップ / 対象一覧から選んで「掘る」 |
| 選択 | マウス移動 / 矢印 / 対象一覧 | 対象一覧 |
| 観察 | 右クリック / O / 観察ボタン | 対象を選んで観察 |
| 記憶一覧 | C / 記憶ボタン | 記憶ボタン |
| 追加の問診 | Q / 問診ボタン | 問診ボタン |
| 会話・カード送り | Enter / Space | 決定 / 次へ |
| 記憶の分類・関連づけ | 画面下の選択欄・ボタン | 同じ選択欄・ボタン |
| ポーズ | Esc / 一時停止 | 一時停止 / 再開 |
| 探索を最初から | R（探索中・ポーズ中） | ポーズ中の再挑戦 |
| 音楽 | M / SOUND | SOUND |

記憶一覧は「探索に戻る」またはEscで閉じます。マップは画面内に収まるのでパン・ピンチ操作は不要です。指のスライド・スクロールやpointercancelでは掘削しません。小さなマスを押しにくい場合は、地図下の対象一覧を利用できます。会話・カード・問診には高解像度のテキスト補助表示があります。

設定画面では音量・ミュート・動きの軽減を変更できます。設定をlocalStorageへ保存します。進行はブラウザメモリ上のみで、再読み込みすると初期化されます。フォーカスが外れると自動ポーズします。

## STAGE 01の構造（ネタバレを含みます）

1. 表層：入口から感情の輪郭を掘り、横方向に広がる分岐へ。
2. 左の記憶「21:47」：隠れた通路を選び、観察してから掘ります。
3. 右の記憶「会議室」：問診で会議室について尋ね、防衛を解放します。
4. 中央の記憶「自分への言葉」：途中の業務メモを調べ、防衛を解放します。
5. 上記3枚はどの順番でも収集できます。分類を終えると中央奥へ進めます。
6. 残響に近づき、会議室の引用と本人の解釈の出どころを結びます。ゲートを開いて帰還します。

謎解きは総当たりの掘削だけでは完了しません。誤った分類・関連づけを選んでもペナルティはなく、具体的な手がかりを読んで選び直せます。

## 表現・技術構成

論理解像度320×180、Canvas実解像度960×540。メインビジュアル、顔アップ、脳の横顔、記憶場面を再利用しました。診療室は患者と室内を一枚の絵に統合し、既存の椅子への着席・床との接地・照明を合わせています。旧透過人物の重畳は使いません。自動生成の既存ゲーム素材やキャラクターの流用はありません。オリジナル画像の制作記録は `public/assets/ART_DIRECTION.md` にあります。

探索マップは頭蓋内の中央に表示します。未知の領域は暗く保ち、掘れる輪郭と記憶を明示します。表層は青紫、中層はマゼンタ、深層は赤紫と黒へ変化します。掘削は約0.2秒の破片、観察・防衛解放は細い光、記憶は短いフェードと文字送り、残響は顔と眼・口の小さな変化で表現しています。動き軽減では揺れ・ノイズ・眼や口の動きを抑えます。

Web AudioによるオリジナルBGMと掘削・観察SEを使用。場面と残響の出現で曲調が変わり、ゲート後は音楽を絞って合成の呼吸音を重ねます。ユーザー操作からのみ音を開始します。無音でも必要な情報は文字・色・模様で分かります。

```text
src/excavation/
  ExcavationBoard.ts       掘削、可視性、集中力、手がかり、問診、謎解き、勝利
  TileTypes.ts             マスの種類、条件、状態
  level01.ts               固定10×12マップ
  ExcavationBoard.test.ts  全6発見順、集中力、封印、進行不能の検証
src/render/
  ExcavationRenderer.ts    盤面・深さ・残響・選択情報の描画
  ExcavationEffects.ts     掘削破片と解放の光
  Art.ts / NovelAssets.ts  既存の診療室・人物・ノベル用画像
src/game/
  Game.ts                  シーン、問診帰還、記憶閲覧、探索アクション
  MapControls.ts           マウス・タップ・右クリック・キャンセル
  Input.ts / TouchControls.ts  キーボード・メニューボタン
  Audio.ts                 合成BGM・SE・呼吸
src/data/memory01.ts       3枚の記憶、分類、追加問診
src/data/story.ts          既存の導入・質問・帰還
src/main.ts               DOMのマップ重畳、カード・問診UI、レスポンシブ表示
```

責務をファイルに細かく分散させるより、小規模でテスト可能な純粋な盤面モデルへまとめています。盤面モデルはDOM・Canvas・Audioに依存しません。掘削済み・発見済みのマス、解放された封印、記憶、手がかり、完了した謎、集中力、問診回数、ゲート状態を保持します。

## 検証

- `npm test`：36件成功。盤面テスト、ゲーム進行統合テスト、タップ入力、既存メニューボタン、音楽のテストです。
- `npm run build`：TypeScript型チェックと本番ビルド成功。
- 6通りすべての記憶発見順からゲートまで到達。通常マスを先に掘りつくした場合も、全6順で復帰できることを検証。
- 掘れないマスでの連打、斜め・遠方、未発見領域、観察範囲、集中力の消費・回復、問診による状態保持、誤った分類、関連づけ、ゲート条件を検証。
- 3つの初回質問それぞれから、追加問診・記憶再閲覧・分類・残響・帰還・診断書・タイトルまで統合テストで確認。
- アプリ内ブラウザでMac表示と390px幅の表示を操作確認。実際のマップクリック、対象一覧、観察、集中力0からの問診再開、記憶3枚、分類の誤答と再試行、関連づけ、帰還、診断書、SESSION COMPLETE、タイトル復帰を確認しています。実機スマートフォンの確認ではありません。

## 残っている課題

- 目標15〜20分に対する初見プレイ時間・理解度・難度の測定は未実施です。解法を知っていれば数分で終わります。掘削回数を増やして引き延ばす調整はしていません。
- 記憶の画像は静止イラストに短いフェード・文字送りを加えた表現です。専用の複数コマCG、声優の音声、録音された環境音は未実装です。
- 上司の残響はオリジナルの簡略化した輪郭・眼・口です。追加の専用イラストや表情差分には磨き込みの余地があります。
- 合成呼吸音・BGMの音量バランス、iPhone Safari / Android実機でのタップと音声は追加検証が必要です。
- セーブ、複数症例、ゲームパッド、マップのパン・ピンチは未実装です。全マップが画面に収まる設計です。
- マップの各マスにアクセシブルな名前とキーボードフォーカスを用意していますが、スクリーンリーダーによる通し操作は未検証です。
