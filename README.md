# BRAIN DIVE — 診断書

STAGE 01「月曜の朝」を、タイトルから診断書・タイトルへの帰還まで遊べる短編心理パズルです。添付仕様書 v1.0 を基準に、Vite + TypeScript + HTML5 Canvas 2D で実装しています。外部API、アカウント、サーバー処理は不要です。

## 公開URL

[ブラウザで遊ぶ](https://shirama-y.github.io/brain-dive/) · [GitHubリポジトリ](https://github.com/Shirama-y/brain-dive)

スマートフォンでもこのURLから直接遊べます。ローカルサーバーの起動は不要です。

## 起動

Node.js **22.12以上**（24 LTS 推奨）とnpmが必要です。Macのターミナルで次を実行してください。

```sh
git clone https://github.com/Shirama-y/brain-dive.git
cd brain-dive
npm install
npm run dev
```

ターミナルに表示される Local URL（通常 `http://127.0.0.1:5173/`）をMacのChromeまたはSafariで開きます。最初にゲーム画面をクリックすると、キーボード操作が有効になります。別のボタンやタブにフォーカスを移した場合も、Canvasをクリックしてください。

```sh
npm test          # パズルとゲーム進行の自動テスト
npm run build    # TypeScript型チェック + dist/ への静的ビルド
npm run preview  # ビルド済みゲームをローカル表示
```

`dist/`は静的ホスティングに配置可能です。HTMLをFinderから直接開くのではなく、上記サーバー経由で表示してください。クラウド同期フォルダで開発中に再読み込みが続くのを避けるため、開発サーバーのファイル監視はポーリングにしています。

## GitHub Pagesへの更新

GitHub Pagesは `main` ブランチの `docs/` を公開します。`docs/` は生成物のため直接編集せず、`src/` を変更してから次を実行します。

```sh
npm test
npm run build:pages
git add src scripts docs package.json package-lock.json index.html vite.config.ts tsconfig.json README.md .gitignore
git commit -m "Update BRAIN DIVE"
git push origin main
```

反映状況はGitHubのActionsタブで確認できます。`docs/.nojekyll` により、Viteの静的ファイルをそのまま配信します。認証情報はリポジトリに保存しません。

## スマートフォンで開く

iPhone / Androidのブラウザ向けに、縦持ち・横持ちの表示と画面内のタッチ操作を追加しています。Macとスマートフォンを**同じWi-Fi**につなぎ、Macで次を実行します。

```sh
npm run dev:mobile
```

ターミナルに出る **Network URL**（例：`http://192.168.1.10:5173/`）をスマートフォンで開いてください。`localhost` / `127.0.0.1` はスマートフォンからはMacを指さないため使いません。Mac側のサーバーを起動したままにしてください。ゲストWi-Fiなど、端末間の通信が分離されているネットワークでは接続できないことがあります。別のネットワークから開くには `dist/` を静的ホスティングに配置する必要があります。

- 会話・記憶・診断書：「決定 / 次へ」。質問や設定は「↑ / ↓」で選択。音量は「− / ＋」。
- パズル：「← / →」で移動、「↶ / ↷」で回転、「↓」で速く落下、「落とす」で即着地。左右と↓は長押し対応です。
- 「一時停止」「再開」「再挑戦」「ヒント」も画面のボタンで操作できます。
- 会話や記憶はCanvasの下にも大きな文字で表示します。縦持ちは画面幅いっぱい、横持ちは操作パネルを右側へ配置します。スマートフォンでは読みやすさを優先して画面幅に合わせて拡大し、PCでは整数倍を保ちます。
- 全画面表示の可否はブラウザによります。通常表示のままでも全操作が可能です。

## 操作

| キー | 診療室・メニュー | パズル |
| --- | --- | --- |
| Enter | 決定・全文表示・次へ | 記憶カードを閉じる |
| Space | 決定・全文表示・次へ | ハードドロップ |
| Z | 決定・全文表示・次へ | 反時計回りに回転 |
| ↑ / ↓ | 選択肢を移動 | ↑ 時計回りに回転 / ↓ ソフトドロップ |
| ← / → | 設定画面の音量変更 | 左右移動（長押し可） |
| X | — | 時計回りに回転 |

## 遊び方

- 軸と子の2個組を落とします。同じ感情を縦・横に4個以上つなげると消去。斜めは対象外です。紫＝不安、桃＝自責、青＝疲労、橙＝怒り。表情・模様でも区別しています。
- 浮いたブロックは落下し、連鎖します。右下の眼の核は固定されています。最初からある灰色の「封じた記憶」6個が診断の対象です。隣接した感情の4個消しで封印→ひび→解放と2段階でほどき、解放したおじゃまが2・4・6個になると記憶が開きます。感情を消した回数だけでは診断は進みません。
- 診断対象のおじゃまを2個解放すると「上司の残響」が現れ、その場で黒い叱責を2個追加します。その後は6ターンごとに1個追加します。叱責は同色消去できませんが、隣の感情を消すと除去できます。上司が追加した叱責は診断の根拠には数えません。
- 記憶3で怒りを解放。次のペアに必ず出現し、以降も3ペアごとに補充されます。怒りを右下の核の上下左右に着地させると帰還します。
- 上が塞がったら失敗です。Enter / Rですぐ再挑戦できます。スコア競争や質問の正誤判定はありません。
- 初期6〜8ペアを含む12ペアは固定順。その後はシード付き乱数です。初見では、最初の紫を左端の紫の上へ置いてみてください。

<details>
<summary>通しプレイ確認用の手順（ネタバレ）</summary>

左から列を1〜8と数えます。回転せず縦向きのまま、ペアを **1 → 3 → 5 → 1 → 1 → 3 → 3 → 5 → 5** 列へ順番にハードドロップします。記憶はEnterで閉じます。この固定手順で3枚を発見できます。次の橙のペアを **8列目** へ落とすと核の上に着地し、帰還します。これは実際の入力処理を使う通しテストでも検証しています。操作の待ち時間で自然落下した場合はRでリセットできます。

## 実装済み

- タイトル、設定、患者の歩行・専用の座り絵への切替（腰・膝・床につく足）、文字送り、3つの質問と返答・記憶ヒントの差分。
- 診療室の暗転 → 専用の顔アップ → 瞳の暗い開口 → 脳内へのフェードイン、約3.8秒の潜行。立ち絵を拡大せず、アップは320×180内へ専用に描画。決定キーでスキップ可能。
- 左向きの横顔の断面内に配置した8×12盤面、2ペアのNEXT、ゴースト、壁際回転、長押し移動、ソフト・ハードドロップ、4個消し、連鎖、固定核、失敗と再挑戦。
- 3つの記憶カード、上司の残響、6ターン周期の妨害、怒り解放・定期補充、核無力化。
- 診療室への帰還、対話、架空の診断書の印字、院内医師の確認・署名と押印、SESSION COMPLETE、タイトル復帰。
- 320×180のCanvasを表示領域内で整数倍拡大。スマートフォンは幅に合わせて拡大縮小し、1倍未満の幅でも比率を維持して縮小。補間無効。フルスクリーン対応。
- オリジナルのコード描画、Web Audioによる短い合成効果音、音量・ミュート・演出軽減、設定保存、自動ポーズ。

## 検証

**検証結果：34件の自動テスト成功、TypeScript型チェック・本番ビルド成功。** スマートフォン相当の390px幅で表示とタッチボタンによる開始・会話・質問・移動・落下・記憶解放を確認しました（実機での検証ではありません）。Macのアプリ内ブラウザでも、開始 → 記憶3枚 → 核無力化 → 帰還 → 診断書 → SESSION COMPLETE → タイトル復帰の一周を操作確認し、コンソールエラーがないことを確認しました。

自動テストは、縦横4連結・斜め無効・5個以上、重力・2連鎖、固定核、叱責、壁際回転・移動制限、出現失敗、水平ペアの分離落下、シード再現性、6ターン妨害、おじゃま2/4/6個解放による記憶、怒り補充、勝利・未解放時の勝利防止、ヒントを確認します。

さらに3つの質問それぞれから、実際のキーボード入力処理を経て記憶3枚 → 核無力化 → 帰還 → 診断書 → タイトルまで到達するシーン統合テストを用意しています。記憶中・ポーズ中の停止、再挑戦、1回限りのヒント、設定保存も確認対象です。追加で、感情だけを消しても診断が進まないこと、封印の2段階解除、上司の出現時の妨害追加、叱責と診断対象の区別、タッチの長押し・複数指・キャンセル・決定操作を確認しています。

## v1仕様から変更したゲーム性

ユーザーの指示により、「感情の消去回数で診断する」ルールを「初期配置のおじゃまを解放して診断する」ルールへ変更しました。診断に関係する記憶の塊と、上司が追加する叱責を見た目・進行上で区別しています。封印は2段階でほどくため、同じ場所の近くで消すことや連鎖に意味があります。上司は診断を進める対象ではなく、発見を妨げる存在です。

着席時は歩行用の立ち絵とは独立した専用ポーズに切り替えます。潜行用の顔も専用のアップ絵を原寸で描画し、立ち絵の引き伸ばしは行いません。暗転から脳内へ移行するまで盤面は停止します。

## 残っている課題・仕様との差分

- ドット絵はプロトタイプのCanvas図形です。歩行のコマ数、残響の表情、神経の密度、押印・帰還演出には磨き込みの余地があります。
- 消去・重力・連鎖は論理上即時に解決し、約0.4秒の解放エフェクトを重ねています。各連鎖の段階的な落下・消去アニメーションは未実装です。
- 日本語はMac標準フォントを論理解像度で描画しています。専用の日本語ビットマップフォントや高解像度テキスト補助レイヤーは未実装です。
- 音楽・環境音・声の収録は未実装。移動・決定・回転・着地・消去・潜行・押印の短い合成音のみです。
- 想定10〜15分に対して、解法を知っていると数分で完走できます。難度・物語の間・ランダム局面の長期バランスは今後のプレイテスト対象です。
- Macのアプリ内ブラウザで表示と操作を確認しています。iPhone Safari / Android実機の独立した互換性検証は未実施です。
- セーブ、複数症例、ゲームパッド、スクリーンリーダー向けの盤面読み上げは未実装です。

作品中の患者・医師・書類はフィクションです。診断書はゲーム専用の文面で、実在の診断書様式を再現していません。
