# BRAIN DIVE — 診断書 / MIND SWEEPER

脳内パズルをマインスイーパーへ変更しました。記憶の分類・関連づけ・防衛ブロック・掘削ルート・集中力システムは撤去しています。

**数字を読み、地雷を避ける。迷ったらカウンセリングで安全なヒントを得る。**

[ブラウザで遊ぶ](https://shirama-y.github.io/brain-dive/) · [GitHub](https://github.com/Shirama-y/brain-dive)

## 起動

Node.js 22.12以上（24推奨）とnpm。

```sh
npm install
npm run dev
```

表示されたローカルURLをMacのブラウザで開いてください。

```sh
npm test           # 盤面・シーン進行・入力・音楽の自動テスト
npm run build      # TypeScript型チェック + dist/へのビルド
npm run preview    # ビルド済みゲームのローカル確認
npm run dev:mobile # 同じWi-Fiのスマートフォンで確認
```

スマートフォンでローカル版を開く場合はNetwork URLを使います。スマホのlocalhostはMacを指しません。HTMLを直接開くのではなく、HTTPサーバー経由で表示してください。

## ルール

- 8列×8行、地雷6個、安全なマス58個のマインスイーパーです。
- 数字は周囲8マスの地雷数。上下左右に加え、斜めも数えます。
- 空白（周囲に地雷0個）は、つながった空白とその周りの数字を自動で開きます。
- 最初に開くマスと、その周囲8マスには地雷を置きません。地雷配置は最初の開封時に確定します。
- 地雷以外の全58マスを開くとクリアし、診療室へ帰還します。旗を正解の場所に立てるだけではクリアになりません。
- 地雷を開くと爆発し、患者がパニックに陥る演出の後、GAME OVERになります。「もう一度」で脳内パズルから再挑戦できます。
- 旗は地雷だと思う場所への印です。正解を保証するものではなく、旗を外すまでそのマスを開けません。
- 時間制限、集中力、スコア、記憶カードの謎解きはありません。

## 心理状態とカウンセリング

盤面は上3行が「叱責の記憶」、中3行が「自分を責める声」、下2行が「疲れ」です。声かけの内容に応じ、その領域を優先して安全マスを見せます。該当する領域を開き終わった場合は、他の領域を支援します。領域の名前・色は気持ちの背景であり、地雷の位置を暗示するものではありません。

相談1回目は3マス、2回目は5マス、3回目以降は7マスまで安全ヒントが出ます。安全マスを開くほど「安心度」が上がり、患者の言葉が「緊張している」→「呼吸が整ってきた」→「少し落ち着いている」へ変わります。これは作品内の進行表示で、臨床尺度ではありません。金色のヒントを開き、また話を聞くことを繰り返すだけでもクリアできます。


パズル中の「カウンセリング」で診療室へ戻り、患者へ声をかけます。どの声かけにも正誤はなく、声かけに対応する気持ちの領域を中心に、安全な未開封マスを複数示します。

- 安全なマスは金色の「◇」で表示し、列・行も文章で知らせます。音がなくても分かります。
- ヒントだけで勝手にマスを開くことはありません。戻ったら金色のマスを自分で開けます。
- 盤面・開いたマス・旗を保持します。誤って旗を置いていた安全マスがヒントになった場合は、その旗を外します。
- カウンセリングに回数制限はありません。推測が必要になっても、繰り返し相談すれば安全に進められます。
- 最初の開封前は、最初に示した3つの安全マスを繰り返し案内します（この段階ではヒント数を増やしません）。その後どこを初手に選んでも、事前の安全ヒントは守られます。
- カウンセリングから戻るとタップ操作を「開く」に戻し、ヒントのマスを選択します。

## 操作

| 操作 | Mac | スマートフォン |
| --- | --- | --- |
| マスを開く | 左クリック / Enter / Space | マスをタップ / 「開く」 |
| 旗を立てる・外す | 右クリック / F / 旗ボタン | 旗ボタン、または「マスタップ」を旗モードへ切替 |
| カウンセリング | Q / H / カウンセリングボタン | カウンセリングボタン |
| マスの選択 | マウス移動 / 矢印 / 対象一覧 | 対象一覧 |
| 会話送り | Enter / Space | 決定 / 次へ |
| ポーズ・再開 | Esc / 一時停止 | 一時停止 / 再開 |
| 再挑戦 | R（パズル中・ポーズ中） / Enter（GAME OVER） | GAME OVERの「もう一度」、ポーズ中の再挑戦 |
| タイトルへ | Esc（GAME OVER） | GAME OVERの「タイトルへ戻る」 |
| 音楽 | M / SOUND | SOUND |

開始画面はメインビジュアルの1つのみです。「はじめる」から診療室へ進みます。音楽のON/OFFと設定も同じ画面にあります。スマホでは盤面を幅いっぱいに大きく表示し、数字を読みやすくしています。マス上のスライドやスクロール、タップのキャンセルでは開封しません。

設定で音量・ミュート・動きの軽減を変更でき、設定のみlocalStorageへ保存します。進行セーブはありません。ブラウザのフォーカスが外れると自動ポーズします。

## 演出

初回の問診後に、カウンセラーが「不安を景色として一緒に眺める」「迷ったら話に戻る」「話せたことが金色の手がかりになる」と説明します。患者の了承を含む4つの会話を、決定で読み進めてから脳内へ進みます。

潜行は3.8秒のザッピング。診療室・固定の患者の顔アップ・盤面をカットで切り替えます。TOPのメインビジュアルや脳内イラスト単体は遷移に挟みません。黒い円や縁の拡大、顔の拡大はありません。動き軽減ON（初期値）は4カット、OFFは8カットと短い水平ノイズ・小さな切替音です。白い全画面フラッシュは使いません。相談後の再入場も「さっき話せたことを、手がかりに」の言葉から始まり、決定でスキップできます。ポーズ中は遷移を止めます。


既存のメインビジュアル、背景と一体化した患者の着席絵、診療室・患者の顔・盤面を切り替えるザッピング演出を維持しています。脳内の横顔の中に盤面を表示し、スマホでは同じ盤面データを大きなグリッドで表示します。

爆発とGAME OVERには、会議室で上司に叱責されている既存のオリジナルイラストを使い、暗い赤紫の色調、画面上の患者の言葉、破片と低い電子音を使います。動き軽減ONでは画面の揺れやノイズを抑え、強い点滅は使いません。音声による叫びは収録していません。

クリア時は音楽を絞り、合成の呼吸音とともに診療室へ戻ります。医師による別の診察・評価・確認を経て、架空の診断書を発行し、SESSION COMPLETEからタイトルへ戻ります。

旧src/excavation/と記憶の分類・関連づけ画面は削除しました。マスの表示用データには、開く前の地雷や数字を含めません。地雷位置はGAME OVERで初めて公開します。

## 検証と残る課題

41件の自動テストとTypeScript・本番ビルドが成功しています。ブラウザでは390×844のスマホ相当表示で開封・旗・相談の安全ヒント、爆発・再挑戦、全58マスの開封から診断書・タイトルへの帰還を確認しました。スマホ実機での検証は未実施です。

自動テストでは初手の安全、斜めを含む数字、空白展開、旗、地雷による失敗、全安全マスでの勝利、相談で盤面が保持されること、ヒントの安全性、誤った旗からの復帰を確認します。100種類の盤面が、繰り返しの相談だけでも推測なしにクリアできることを検証します。

さらに、初回質問3通りからカウンセリング・勝利・診断書・タイトルまで、爆発からGAME OVER・再挑戦まで、ポーズ、入力、音楽、設定保存をテストします。

残る課題は、初見プレイヤーによる地雷密度・ヒント頻度の調整、iPhone Safari / Android実機の互換性確認、患者の専用表情アニメーション・声の追加です。乱数盤面そのものが数字だけで常に解けることは保証していませんが、無制限の安全ヒントで推測を避けられます。
