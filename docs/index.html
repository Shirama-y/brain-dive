遊び方・アクセシビリティ

8×8マス、地雷6個のマインスイーパーです。数字はそのマスの周囲8マスにある地雷の数です。斜めも数えます。空白は周囲も自動的に開きます。地雷以外の58マスをすべて開けばクリア。地雷を開くと患者がパニックに陥り、ゲームオーバーです。最初の一手とその周囲は安全です。各領域の安全なマスには、患者の記憶の断片が1つずつ隠れています。開くと場面の絵と患者のひと言が、約3秒のカットインで現れます。決定でスキップでき、複数見つけた場合は順番に流れます。追加の問題や正解選びはありません。

左クリック / タップ / Enterで開く、右クリック / Fで旗。スマートフォンでは「マスタップ」を旗に切り替えると旗を立てられます。旗のマスは旗を外すまで開きません。カウンセリング（Q / H）で患者に声をかけると、話した気持ちの領域を中心に、安全な3〜7マスが金色に光ります。上は叱責の記憶、中は自責の声、下は疲れ。金色を開くだけでも進められ、安心度に応じて患者の言葉が変わります。何度でも利用でき、盤面は保持されます。Escでポーズ、Rで再挑戦。音量と動きの軽減は設定で変更できます。
