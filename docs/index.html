遊び方・アクセシビリティ

灰色の記憶の塊の隣で、同じ感情を縦・横に4つ消します。高さの違う6つの塊は足場にもなります。隣接消去2回で封印がほどけ、塊を取り除くと診断が進みます。2・4・6個の解放で記憶が現れ、上司の声がおじゃまを増やします。3枚そろうと「怒り」が解禁。橙色の怒りを、右下の黒い核の隣に着地させてください。

会話は Enter / Z / Space、質問は ↑ ↓ で選択。パズルは Z で逆回転、↓ で速く落下、H で一度だけヒント、R で再挑戦。設定で音量と動きの軽減を変更できます。スマートフォンでは画面下のボタンで同じ操作ができます。左右と「速く」は長押しできます。セーブはありません。
